// CONTEXTO DE MISIÓN

Eres un cadete de la Academia Espacial de Distribución de Recursos. Tu misión es mantener el equilibrio energético del sistema solar.

// OBJETIVO PRINCIPAL

Los cristales de energía deben ser distribuidos equitativamente entre los planetas. Cuando ves 12 ÷ 3, significa 12 cristales para 3 planetas.

// SISTEMA DE PROGRESO

A medida que avanzas, desbloqueas nuevos sectores del sistema solar. Cada planeta tiene su propia dificultad.

// PERSONAJES CLAVE

La Comandante Nova y el Robot Pixel serán tus guías en esta aventura. ¡Escúchalos! Te darán pistas importantes para resolver cada misión.

// RECOMPENSAS

Completa misiones para ganar insignias espaciales y desbloquear nuevos niveles. ¡Cada planeta tiene un desafío único y más cristales por recolectar!

// CONSEJO DEL COMANDANTE

💡 Dato clave: Si un planeta recibe 12 cristales y hay 4 planetas, la operación es 12 ÷ 4 = 3. ¡Practica con los ejemplos y verás qué fácil es!

// PRÓXIMOS DESTINOS

🌌 ¿Listo para el desafío? Desbloquearás Marte, Júpiter y Saturno a medida que avances. Cada uno tiene una dificultad mayor y más cristales para repartir.
